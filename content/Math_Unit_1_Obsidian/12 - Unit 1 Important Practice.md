# Unit 1 Important Practice

## Mathematical Logic

- Identify whether a sentence is a statement.
- Identify atomic and compound statements.
- Convert English statements into symbolic form.
- Construct truth tables for logical expressions.
- Find the truth table of `p → q`.
- Find the truth table of `p ↔ q`.
- Find converse, inverse and contrapositive of `p → q`.
- Determine whether an expression is a tautology, contradiction or contingency.
- Prove two propositions are logically equivalent.
- Simplify expressions using laws of logic.
- Use De Morgan's laws.
- Work with NAND and NOR.

## Set Theory

- Define a set and cardinality.
- Check membership.
- Check whether two sets are equal.
- Determine subsets and proper subsets.
- Find the power set.
- Perform union and intersection.
- Find set difference.
- Find absolute complement.
- Identify disjoint sets.
- Apply properties of sets.
- Draw Venn diagrams.
- Solve two-set inclusion-exclusion problems.
- Solve three-set inclusion-exclusion problems.

## Must-Memorize Formulas

### Logic

`p → q ≡ ¬p ∨ q`

`p ↔ q ≡ (p → q) ∧ (q → p)`

`p → q ≡ ¬q → ¬p`

### Power Set

`|P(A)| = 2ⁿ` when `|A| = n`

### Two Sets

`|A ∪ B| = |A| + |B| - |A ∩ B|`

### Three Sets

`|A ∪ B ∪ C|`
`= |A| + |B| + |C|`
`- |A ∩ B| - |B ∩ C| - |A ∩ C|`
`+ |A ∩ B ∩ C|`
