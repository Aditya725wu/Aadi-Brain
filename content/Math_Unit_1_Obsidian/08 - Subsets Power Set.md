# Subsets and Power Set

## Subset

A is a subset of B if every element of A is also an element of B.

`A ⊆ B`

## Proper Subset

A is a proper subset of B when:

`A ⊆ B`

and

`A ≠ B`

Notation:

`A ⊂ B`

## Power Set

The power set of A is the collection of all possible subsets of A.

Notation:

`P(A)`

If:

`|A| = n`

then:

`|P(A)| = 2ⁿ`

### Example

`A = {a,b}`

`P(A) = {∅, {a}, {b}, {a,b}}`

Therefore:

`|P(A)| = 4`

## Important Distinction

An element and a subset are different concepts.

For example, if:

`A = {1,2,3}`

then:

`1 ∈ A`

but:

`{1} ⊆ A`
