# Venn Diagrams

A Venn diagram represents sets using circles inside a rectangle representing the universal set.

## Basic Regions

- Rectangle → Universal set `U`
- Circle → Set
- Overlapping region → Intersection
- Combined circles → Union

## Important Representations

### Union

`A ∪ B`

Represents all elements in A or B.

### Intersection

`A ∩ B`

Represents elements common to A and B.

### Complement

`A'`

Represents elements in U but not in A.

### Difference

`A - B`

Represents elements in A but not in B.

## Solving Venn Diagram Problems

1. Draw the universal set.
2. Draw the required circles.
3. Put the common/triple intersection first when given.
4. Calculate pair-only regions.
5. Calculate single-only regions.
6. Add all regions.
7. Calculate the "none" region if required.
