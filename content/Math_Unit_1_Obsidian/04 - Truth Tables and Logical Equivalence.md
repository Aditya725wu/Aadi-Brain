# Truth Tables and Logical Equivalence

## Truth Table

A truth table lists all possible truth values of the propositions and evaluates the complete logical expression.

### Number of Rows

For `n` propositions:

`Number of rows = 2ⁿ`

Examples:

- 2 propositions → `2² = 4` rows
- 3 propositions → `2³ = 8` rows

## Tautology

A proposition whose final truth value is **True for every possible combination**.

Example:

`p ∨ ¬p`

## Contradiction

A proposition whose final truth value is **False for every possible combination**.

Example:

`p ∧ ¬p`

## Contingency

A proposition whose truth value is sometimes True and sometimes False.

## Logical Equivalence

Two propositions are logically equivalent if their truth-table final columns are identical.

Symbol:

`P ≡ Q`

## Proving Logical Equivalence

1. Construct the truth table.
2. Evaluate both expressions.
3. Compare the final columns.
4. If they are identical, the expressions are logically equivalent.
