# Set Operations and Properties

## Union

`A ∪ B = {x | x ∈ A or x ∈ B}`

Example:

`A = {1,2,3}`

`B = {3,4,5}`

`A ∪ B = {1,2,3,4,5}`

## Intersection

`A ∩ B = {x | x ∈ A and x ∈ B}`

`A ∩ B = {3}`

## Disjoint Sets

If:

`A ∩ B = ∅`

then A and B are disjoint.

## Difference

`A - B = {x | x ∈ A and x ∉ B}`

Example:

`A = {1,2,3,4}`

`B = {3,4,5}`

`A - B = {1,2}`

Generally:

`A - B ≠ B - A`

## Absolute Complement

The complement of A with respect to U:

`A' = U - A`

# Properties of Sets

## Identity

`A ∪ ∅ = A`

`A ∩ U = A`

## Domination

`A ∪ U = U`

`A ∩ ∅ = ∅`

## Idempotent

`A ∪ A = A`

`A ∩ A = A`

## Commutative

`A ∪ B = B ∪ A`

`A ∩ B = B ∩ A`

## Associative

`(A ∪ B) ∪ C = A ∪ (B ∪ C)`

`(A ∩ B) ∩ C = A ∩ (B ∩ C)`

## Distributive

`A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)`

`A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`

## De Morgan's Laws

`(A ∪ B)' = A' ∩ B'`

`(A ∩ B)' = A' ∪ B'`

## Absorption

`A ∪ (A ∩ B) = A`

`A ∩ (A ∪ B) = A`

## Complement

`A ∪ A' = U`

`A ∩ A' = ∅`

## Double Complement

`(A')' = A`
