# Set Theory Basics

## Set

A set is a collection of well-defined objects.

Example:

`A = {1, 2, 3, 4, 5}`

The objects in a set are called **elements** or **members**.

## Cardinality

The number of unique elements in a set.

Notation:

`|A|`

Example:

`A = {1,2,3,4}`

`|A| = 4`

## Finite Set

A set having a finite number of elements.

## Infinite Set

A set having infinitely many elements.

## Membership

`a ∈ A` → a belongs to A.

`a ∉ A` → a does not belong to A.

## Equal Sets

Two sets are equal if they contain exactly the same elements.

Example:

`A = {1,2,3}`

`B = {3,2,1}`

Therefore:

`A = B`

Order does not matter in a set.

## Null / Empty Set

A set containing no elements.

Symbols:

`∅` or `{}`

Important:

`∅ ⊆ A`

for every set A.

## Universal Set

The set containing all objects under consideration.

Symbol:

`U`
