# Implication, Biconditional, Converse, Inverse and Contrapositive

## Implication

`p → q`

Read as: **If p, then q.**

| p | q | p → q |
|---|---|---|
| T | T | T |
| T | F | F |
| F | T | T |
| F | F | T |

### Important

`p → q` is false only when `p = T` and `q = F`.

### Equivalent Form

`p → q ≡ ¬p ∨ q`

### Meaning

- p is sufficient for q.
- q is necessary for p.
- p implies q.

## Converse

Original:

`p → q`

Converse:

`q → p`

## Inverse

Original:

`p → q`

Inverse:

`¬p → ¬q`

## Contrapositive

Original:

`p → q`

Contrapositive:

`¬q → ¬p`

### Important Equivalence

`p → q ≡ ¬q → ¬p`

## Biconditional

`p ↔ q`

Read as: **p if and only if q (p iff q).**

| p | q | p ↔ q |
|---|---|---|
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | T |

`p ↔ q ≡ (p → q) ∧ (q → p)`

p is necessary and sufficient for q.
