# Unipolar NRZ

## Rule
- `1 → +V`
- `0 → 0V`

## NRZ
NRZ = Non-Return-to-Zero. The signal does not return to zero during the bit interval.

## Example
Data: `1 0 1 1 0`

Signal: `+V  0V  +V  +V  0V`

## Limitations
- Long runs can cause synchronization problems.
- DC component can be present.

## Memory
**1 → +V, 0 → 0V**
