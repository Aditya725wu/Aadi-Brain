# ☁️ Basic Cloud Computing

## What is Cloud Computing?

Cloud computing means using computing resources over the internet instead of owning and maintaining physical hardware yourself.

Cloud resources can include:

- 🖥️ Servers
- 💾 Storage
- 🗄️ Databases
- 🌐 Networking
- ⚙️ Applications
- 🤖 AI/ML services

### Simple Example

Instead of buying and maintaining a physical server:

User/Developer
↓
Internet
↓
Cloud Provider
↓
Virtual Server

The cloud provider manages the underlying physical infrastructure.

# Important Characteristics of Cloud

## 1. On-Demand

Resources can be created whenever they are required.

Example:

We can create an EC2 instance when we need a server.

## 2. Scalability

Scalability means increasing or decreasing resources according to workload.

Example:

If a website gets more users, we can increase its computing resources.

## 3. Elasticity

Elasticity means automatically increasing or decreasing resources based on demand.

Example:

Traffic increases → resources increase

Traffic decreases → resources decrease

## 4. Pay-as-you-go

We generally pay according to the resources/services we consume.

## 5. High Availability

Cloud applications can be designed using multiple servers or locations so that the application can continue working even if one resource fails.

# Cloud Service Models

There are three important cloud service models:

1. IaaS
2. PaaS
3. SaaS

---

# 1. IaaS

IaaS = Infrastructure as a Service

The cloud provider provides infrastructure such as:

- Virtual Machines
- Storage
- Networking

Example:

AWS EC2

The user manages more of the operating system and software stack.

### Simple Structure

Application
↓
Operating System
↓
Virtual Machine
↓
Cloud Infrastructure

---

# 2. PaaS

PaaS = Platform as a Service

The cloud provider manages the underlying infrastructure and platform.

The developer mainly focuses on the application/code.

Example:

AWS Elastic Beanstalk

### Simple Structure

Application
↓
Platform
↓
Infrastructure

---

# 3. SaaS

SaaS = Software as a Service

The complete software is provided through the internet.

The user simply uses the application.

Examples:

- Gmail
- Google Docs
- Microsoft 365

### Simple Structure

User
↓
Software
↓
Cloud

---

# Easy Way to Remember

IaaS → Infrastructure

PaaS → Platform

SaaS → Software

# Cloud Deployment Models

## 1. Public Cloud

Cloud infrastructure is provided by a cloud provider and used by multiple customers.

Examples:

- AWS
- Azure
- Google Cloud

## 2. Private Cloud

Cloud infrastructure is dedicated to a particular organization.

## 3. Hybrid Cloud

Combination of:

Private Cloud + Public Cloud

An organization can keep some workloads in its private infrastructure and use public cloud services for other workloads.

# Interview Questions

## What is Cloud Computing?

Cloud computing is the delivery of computing resources such as servers, storage, databases, networking and applications over the internet.

## What are the three cloud service models?

The three main service models are:

- IaaS
- PaaS
- SaaS

## What is IaaS?

IaaS provides infrastructure such as virtual machines, storage and networking through the cloud.

Example: AWS EC2.

## What is PaaS?

PaaS provides a platform where developers can build and deploy applications without managing the underlying infrastructure.

## What is SaaS?

SaaS provides ready-to-use software through the internet.

Example: Gmail.

## What is scalability?

Scalability is the ability to increase or decrease resources according to workload requirements.

## What is elasticity?

Elasticity is the ability of a system to automatically adjust resources according to changing demand.

## What is AWS?

AWS stands for Amazon Web Services. It is a cloud computing platform that provides services such as compute, storage, databases, networking and security.
