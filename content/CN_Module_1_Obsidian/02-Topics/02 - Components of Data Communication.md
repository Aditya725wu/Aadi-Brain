# Components of Data Communication

## Five basic components

1.  **Message** --- information to be communicated.
2.  **Sender** --- device that sends the data.
3.  **Receiver** --- device that receives the data.
4.  **Transmission medium** --- physical/wireless path.
5.  **Protocol** --- rules governing communication.

## Diagram

``` text
Sender → Transmission Medium → Receiver
          ↑
       Protocol
Data/Message travels through the medium
```

## Exam tip

If asked "components", give all five and one line for each.
