# Data Communication

## Definition

Data communication is the exchange of data/information between devices
through a communication medium.

## Core idea

``` text
Sender → Transmission Medium → Receiver
```

## Exam answer

Write: 1. Definition. 2. Sender/source. 3. Data/message. 4. Transmission
medium. 5. Receiver/destination. 6. Mention that rules/protocols govern
communication.

## Sample

**Q. Explain data communication with a suitable diagram.**

Answer skeleton: \> Data communication is the exchange of data between
two or more devices through a transmission medium according to agreed
rules. Draw sender → medium → receiver and label the data/message.
