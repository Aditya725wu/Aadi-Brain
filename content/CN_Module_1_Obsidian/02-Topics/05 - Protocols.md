# Protocols

## Definition

A protocol is a set of rules that governs data communication. It
determines **what** is communicated, **how** it is communicated, and
**when** it is communicated.

## Three key elements

### 1. Syntax

Structure or format of the data; tells how bits/fields are arranged and
read.

### 2. Semantics

Meaning of the bits and what action a field represents.

### 3. Timing

When data should be sent and the speed at which it should be
sent/received.

## Memory

**Syntax = structure** **Semantics = meaning** **Timing = when/speed**
