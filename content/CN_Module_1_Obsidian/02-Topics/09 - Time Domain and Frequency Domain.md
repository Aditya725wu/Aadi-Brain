# Time Domain and Frequency Domain

## Time domain

Shows **amplitude versus time**.

It tells us how the signal changes over time.

## Frequency domain

Shows **amplitude versus frequency**.

It tells us which frequency components are present.

## Pure sine wave

A single-frequency sine wave appears as one spike in the frequency
domain.

``` text
Time domain:        Frequency domain:

    /\                  |
   /  \                 |
__/    \__          ____|______→ f
                         f
```

## Multiple sine waves

Three sine waves can be represented by three spikes.

### Important distinction

**Frequency domain** = representation/graph.

**Discrete frequencies** = individual separated frequency values shown
in that representation.
