# Bit Rate and Bit Length

## Bit rate

Number of bits transmitted per second.

\[ Bit Rate=`\frac{\text{number of bits}}{\text{time}}`{=tex} \]

Unit: bps.

## Bit length

Physical distance occupied by one bit in a transmission medium.

Conceptually:

\[ Bit Length=`\frac{\text{propagation speed}}{\text{bit rate}}`{=tex}
\]

## Do not confuse

-   Bit rate → bits/second.
-   Propagation speed → metres/second.
-   Bit length → metres/bit.
