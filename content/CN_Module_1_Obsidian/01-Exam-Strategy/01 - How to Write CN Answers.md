# ✍️ How to Write Computer Networks Answers

## Golden structure

For a 4--6 mark theory question:

1.  **Definition / introduction --- 1--2 lines**
2.  **Main explanation --- numbered points**
3.  **Diagram / format --- whenever applicable**
4.  **Example --- 1 short example**
5.  **Formula / key relation --- if applicable**
6.  **Conclusion / one-line takeaway**

Do not write a large paragraph when the question asks for points.

## For "Explain"

Use:

> **Definition → Working → Diagram → Example → Key point**

## For "Calculate"

Always show:

``` text
Given:
Formula:
Substitution:
Calculation:
Final answer with unit:
```

Never jump directly to the final number.

## For "Draw and explain"

1.  Draw a clean labelled diagram.
2.  Name every important field/layer.
3.  Explain each part in the same order as the diagram.

## For "Elaborate"

Break the answer into subheadings instead of one paragraph.

Example:

### Shannon Capacity

Definition + formula + variable meanings + short interpretation.

### SNR

Definition + formula + meaning.

### Nyquist Bit Rate

Definition + formula + variable meanings.

## For scenario questions

First identify the concept:

> "The situation describes \_\_\_ because \_\_\_."

Then explain the mechanism.

## Exam language

Prefer precise phrases:

-   "Bandwidth is the difference between the highest and lowest
    frequencies..."
-   "Attenuation is loss of energy, resulting in a weaker signal."
-   "Distortion changes the form or shape of a signal."
-   "Noise is an unwanted signal added during transmission."

## Avoid

-   Unnecessary history.
-   Very long introductions.
-   Unlabelled diagrams.
-   Formula without variable meanings.
-   Final numerical answer without units.
-   Mixing attenuation, distortion and noise.
