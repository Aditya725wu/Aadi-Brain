# 🎯 Marks-wise Answer Format

## 1--2 marks

-   Definition
-   2--3 key points
-   Formula if relevant

## 3 marks

-   Definition
-   3--4 points
-   Small diagram/example if useful

## 4 marks

-   Definition
-   Working/explanation
-   Diagram
-   Example or key conclusion

## 5--6 marks

-   Short introduction
-   Detailed numbered explanation
-   Proper diagram/table
-   Formula/example where applicable
-   Short conclusion

## For a 6-mark numerical

Use:

``` text
Given:
B = ...
L = ...
SNR = ...

Required:
...

Formula:
...

Substitution:
...

Answer:
...
```

## Important

The exact marks in the provided PYQs show that WCE asks both short and
long structured answers. Match the depth to the marks.
