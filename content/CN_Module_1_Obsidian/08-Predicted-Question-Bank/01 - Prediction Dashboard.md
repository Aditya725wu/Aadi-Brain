# 🔮 CN Module 1 Prediction Dashboard

> **Not a guaranteed prediction.** This is a pattern-based question bank built from the uploaded Module 1 material and observed WCE CN papers.

## 🔴 Very high preparation priority

### 1. Transmission impairment scenario
**Possible form:** “A signal becomes weaker, its shape changes, and unwanted disturbances are observed. Identify and explain the impairments.”

**Answer:** attenuation, distortion, noise.

### 2. OSI encapsulation scenario
**Possible form:** “A user opens a web page. Explain encapsulation and decapsulation and roles of Network and Transport layers.”

### 3. OSI vs TCP/IP comparison
**Possible form:** “Compare layer structure, functions and practical use; show mapping.”

### 4. Nyquist numerical
**Possible form:** Given B and L, calculate maximum bit rate.

### 5. Shannon numerical
**Possible form:** Given B and SNR, calculate channel capacity.

### 6. Combined Nyquist + Shannon numerical
**Possible form:** Find theoretical upper limit using Shannon, choose a practical bit rate, then determine required signal levels using Nyquist.

## 🟠 High preparation priority

### 7. Bandwidth numerical
Given lowest and highest frequency, find bandwidth.

### 8. SNR numerical
Given signal/noise powers, find SNR and SNRdB.

### 9. Time/frequency-domain diagram
Given frequency components, draw/interpret the frequency-domain spikes.

### 10. Composite periodic signal
Explain decomposition into discrete frequencies.

### 11. Signal-level problem
Given L, find bits per signal element; discuss reliability as levels increase.

### 12. Wavelength/period problem
Given f and v, calculate T and λ.

## Application twists to practice
- “A factory network is near motors…” → induced noise.
- “Two adjacent wires interfere…” → crosstalk.
- “Lightning causes spikes…” → impulse noise.
- “A composite signal changes shape after transmission…” → distortion.
- “A link has a fixed bandwidth but higher SNR…” → Shannon capacity changes.
- “A modem uses 16 levels…” → log2(L).
- “A spectrum analyzer shows spikes…” → discrete frequency components.
- “A browser requests a remote server…” → encapsulation/decapsulation.

## Prediction rule
Prepare the **question family**, not one memorized sentence. An examiner can change numbers, context, or wording while testing the same concept.
