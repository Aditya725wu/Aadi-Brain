# 🔮 Signal Levels

## Question
A system uses 32 signal levels. Find bits per signal element and discuss the reliability trade-off.

## Expected answer structure
1. State the definition/concept.
2. Write the relevant formula or draw the required diagram.
3. Substitute values / map scenario details.
4. Give the final result with units.
5. Add one interpretation sentence.

## Examiner twist
The same concept may be asked with different numbers, a real-world context, or a comparison instead of a direct question.
