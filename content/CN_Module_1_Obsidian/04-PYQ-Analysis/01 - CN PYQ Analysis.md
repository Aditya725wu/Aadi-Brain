## What the papers show

### Pattern A --- Definition / short theory

Examples: - Define static routing. - Define propagation delay. - Define
round-trip time. - Explain routing-table entries.

**Answer style:** definition + 2--4 precise points.

### Pattern B --- Long theory

Examples: - Explain transmission impairments. - Draw and explain IPv4
header. - Explain OSI encapsulation/decapsulation. - Compare OSI and
TCP/IP.

**Answer style:** definition → labelled diagram → field/layer
explanation → example/use.

### Pattern C --- Numerical

Examples: - IPv4 subnetting. - Go-Back-N sequence number. - Token-ring
cycle time.

**Answer style:** Given → Required → Formula → Substitution → Final
answer with unit.

### Pattern D --- Data-link mechanisms

Examples: - Go-Back-N ARQ. - Selective Repeat ARQ. - Byte stuffing. -
CSMA/CD vs CSMA/CA. - Ethernet frame.

**Answer style:** mechanism + sequence/diagram + step-by-step working +
comparison if asked.

### Pattern E --- Encoding

The 2026 paper asks: \> For binary sequence `110010`, draw waveforms for
Unipolar NRZ, Polar NRZ, Bipolar AMI and Manchester encoding. Clearly
mark bit boundaries and transitions.

This means the answer must be **drawn**, not only described.

### Pattern F --- Multiplexing

The 2026 paper asks to explain and compare: - FDM - TDM - WDM

Include working principle + one application/advantage + comparison
table.

## Question wording → expected answer

  Wording          What examiner expects
  ---------------- ----------------------------------------
  Define           Exact definition + 1--2 points
  Explain          Definition + working + example
  Elaborate        Detailed subheadings + formula/diagram
  Compare          Table
  Draw             Correct labelled diagram/waveform
  Calculate        Full numerical steps
  Illustrate       Explanation + example/diagram
  Given scenario   Identify concept + apply it

## PYQ lesson

Do not prepare only definitions. WCE's CN questions combine: -
conceptual theory, - diagrams, - numerical problems, - protocol
mechanisms, - and comparisons.

So every topic note in this vault contains: **Concept → Exam definition
→ Diagram/formula → Sample question → Answer structure.**
