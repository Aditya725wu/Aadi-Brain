# 📝 Marks → Answer Depth Matrix

| Marks | What to write | Typical CN structure |
|---:|---|---|
| 1–2 | Direct concept | Definition + one key point |
| 3 | Concept with justification | Definition + 2–3 points + mini diagram/example |
| 4 | Explain/compare/application | Definition + working + labelled diagram/table + example |
| 5 | Detailed theory/problem | Intro + stepwise working + diagram + application/conclusion |
| 6 | Full analytical answer | Intro + mechanism + comparison/diagram + application + conclusion |

## For scenario questions
Never answer only with the name of the concept. Explain **why the scenario matches it**.

## For numerical questions
Never write only the final number. Show the formula and substitution so partial marks are possible.
