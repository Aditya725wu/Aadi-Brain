# Sensors

## What is a Sensor?

A sensor is a device that detects or measures a physical quantity and provides information that a system can process.

## Examples

| Sensor | Measures |
|---|---|
| Temperature Sensor | Temperature |
| Humidity Sensor | Humidity |
| Soil Moisture Sensor | Soil Moisture |
| Ultrasonic Sensor | Distance |
| Light Sensor | Light Intensity |

## Remember

> Sensor = Collects Data
