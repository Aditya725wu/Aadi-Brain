# Bit Rate and Bit Length

## Bit Rate

Bit rate is the number of bits transmitted per second.

Unit: **bits per second (bps)**.

Examples:

- 1000 bps = 1 kbps
- 1,000,000 bps = 1 Mbps

## Bit Length

Bit length is the physical distance occupied by one bit on the transmission medium.

> **FORMULA**
>
> `Bit length = propagation speed × bit duration`

Since:

`bit duration = 1 / bit rate`

we can also write:

> **FORMULA**
>
> `Bit length = propagation speed / bit rate`

## Numerical Example

Given:

`Propagation speed = 2 × 10^8 m/s`

`Bit rate = 1 Mbps = 10^6 bps`

Then:

`Bit length = (2 × 10^8)/(10^6)`

`= 200 m`

Therefore, one bit occupies **200 m** of the medium.

## Important Difference

| Bit Rate | Propagation Speed |
|---|---|
| Bits transmitted per second | Speed of signal travel |
| bps | m/s |
