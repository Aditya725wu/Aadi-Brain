# Analog and Digital

## Analog Data

Analog data are **continuous** and take continuous values.

Example: continuously varying voice signal.

## Digital Data

Digital data have **discrete states** and take discrete values.

Example: binary data represented using 0 and 1.

---

# Analog Signal

An analog signal can have an **infinite number of values within a range**.

Its waveform changes continuously.

# Digital Signal

A digital signal can have only a **limited number of values**.

It commonly uses discrete signal levels.

## Comparison

| Analog | Digital |
|---|---|
| Continuous | Discrete |
| Infinite values in a range | Limited number of values |
| Smooth variation | Discrete levels |
| Example: voice waveform | Example: binary data |

## Important Point

Data and signals are different concepts:

- **Data** = information
- **Signal** = electrical/electromagnetic representation used for transmission
