# Data Flow

Data flow describes the direction in which data moves between two communicating devices.

There are three types.

## 1. Simplex

Communication takes place in **one direction only**.

`Sender ─────────→ Receiver`

The receiver cannot send data back to the sender.

**Example:** Traditional television broadcasting.

### Key point
**One-way communication.**

---

## 2. Half-Duplex

Communication takes place in **both directions, but not at the same time**.

`A ─────→ B`
`A ←───── B`

One device sends while the other receives, then the direction can be reversed.

**Example:** Walkie-talkie.

### Key point
**Two-way, but one direction at a time.**

---

## 3. Full-Duplex

Communication takes place in **both directions simultaneously**.

`A ⇄ B`

Both devices can send and receive at the same time.

**Example:** Telephone conversation.

### Key point
**Two-way at the same time.**

## Comparison

| Feature | Simplex | Half-Duplex | Full-Duplex |
|---|---|---|---|
| Direction | One | Both | Both |
| Simultaneous communication | No | No | Yes |
| Example | TV broadcast | Walkie-talkie | Telephone |
