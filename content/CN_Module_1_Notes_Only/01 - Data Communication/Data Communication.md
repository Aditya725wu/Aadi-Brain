# Data Communication

## Definition

**Data communication** is the exchange of data between two devices through some form of transmission medium.

**Telecommunication** means communication at a distance.

Data refers to information presented in a form agreed upon by the parties creating and using the data.

## Components of a Data Communication System

A data communication system has five basic components:

1. **Message** — the information to be communicated.
2. **Sender** — the device that sends the data.
3. **Receiver** — the device that receives the data.
4. **Transmission medium** — the physical path through which data travels.
5. **Protocol** — the set of rules governing communication.

### Basic flow

`Sender → Transmission Medium → Receiver`

The **protocol** controls how the communication takes place.

## Data Representation

### Text
Text is represented using character-coding systems such as **ASCII** and **Unicode**.

### Images
An image is represented using **pixels**. Pixel values may represent grayscale or RGB information.

### Audio
Audio is represented as an electrical/electromagnetic signal after suitable conversion.

### Video
Video is a sequence of images/frames, usually accompanied by audio.

## Important Point

Before transmission, data must be transformed into **electromagnetic signals**.

## Exam Definition

> Data communication is the exchange of data between two devices through a transmission medium according to a set of communication rules called protocols.
