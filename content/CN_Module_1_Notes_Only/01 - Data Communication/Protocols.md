# Protocols

## Definition

A **protocol** is a set of rules that governs data communication.

It determines:

- **What** is communicated
- **How** it is communicated
- **When** it is communicated

## Elements of a Protocol

There are three key elements:

### 1. Syntax

Syntax means the **structure or format of the data**.

It indicates how the bits are arranged and how fields are separated.

**Think:** What does the message look like?

### 2. Semantics

Semantics means the **meaning of each section of the data**.

It tells the receiver what action a particular field represents.

**Think:** What does the message mean?

### 3. Timing

Timing specifies:

- When data should be sent
- The speed at which data should be sent
- The speed at which data should be received

**Think:** When and how fast?

## Easy Memory Trick

**Syntax = Structure**

**Semantics = Meaning**

**Timing = When/Speed**

## Exam Definition

> A protocol is a set of rules that governs data communication and defines what is communicated, how it is communicated, and when it is communicated.
